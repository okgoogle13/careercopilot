# Skeleton

The `Skeleton` component provides a visual placeholder for content that is loading. It's designed to improve perceived performance by showing a preview of the content structure before the actual content loads.

## Basic Usage

```jsx
import { Skeleton } from '../components/ui/feedback/Skeleton';

function LoadingContent() {
  return (
    <div>
      <Skeleton variant="text" width={200} />
      <Skeleton variant="circular" width={40} height={40} />
      <Skeleton variant="rectangular" width={210} height={60} />
    </div>
  );
}
```

## Animation

You can control the animation of the skeleton with the `animation` prop:

- `pulse` (default): A pulsing animation
- `wave`: A shimmering wave animation
- `false`: No animation

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| variant | 'text' \| 'circular' \| 'rectangular' \| 'rounded' | 'text' | The type of skeleton to display |
| animation | 'pulse' \| 'wave' \| false | 'pulse' | The animation type |
| width | number \| string | - | The width of the skeleton |
| height | number \| string | - | The height of the skeleton |
| sx | object | - | Custom styles |

## Best Practices

- Use skeleton loaders when the content takes more than 300ms to load
- Match the skeleton shape to the content it will replace
- Use appropriate animation to indicate loading without being distracting
- Consider using skeleton loaders for above-the-fold content first
- Keep the skeleton design simple and lightweight
