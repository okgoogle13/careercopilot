# Toast

The `Toast` component is used to display brief, non-intrusive notifications to users. It's built on top of Material-UI's `Snackbar` and `Alert` components.

## Basic Usage

```jsx
import { Toast } from '../components/ui/feedback/Toast';

function Example() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setOpen(true)}>Show Toast</Button>
      <Toast
        open={open}
        onClose={() => setOpen(false)}
        message="This is a toast message"
      />
    </>
  );
}
```

## Using with Toast Context

For easier toast management across your application, use the `ToastProvider` and `useToast` hook:

```jsx
import { ToastProvider, useToast } from '../components/ui/feedback/ToastContext';

function App() {
  return (
    <ToastProvider>
      <YourApp />
    </ToastProvider>
  );
}

function YourComponent() {
  const toast = useToast();

  const handleClick = () => {
    toast.success('Operation completed successfully!');
  };

  return <Button onClick={handleClick}>Show Success Toast</Button>;
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| open | boolean | false | Controls whether the toast is open |
| onClose | function | - | Callback when the toast is closed |
| message | string | - | The message to display |
| severity | 'error'\|'warning'\|'info'\|'success' | 'info' | The severity of the toast |
| anchorOrigin | { vertical: 'top'\|'bottom', horizontal: 'left'\|'center'\|'right' } | { vertical: 'bottom', horizontal: 'center' } | The position of the toast |
| autoHideDuration | number | 6000 | Auto hide duration in milliseconds |
| action | ReactNode | - | Additional action to display |
| className | string | - | Additional CSS class name |
| sx | object | - | Additional styles |
