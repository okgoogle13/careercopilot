# EmptyState

The `EmptyState` component is used to communicate to users when there's no content to display. It provides a clear message and often includes an icon and a call-to-action.

## Basic Usage

```jsx
import { EmptyState } from '../components/ui/feedback/EmptyState';
import InboxIcon from '@mui/icons-material/Inbox';

function EmptyInbox() {
  return (
    <EmptyState
      icon={<InboxIcon fontSize="large" />}
      title="No Messages"
      description="You don't have any messages yet. When you do, they'll appear here."
      action={
        <Button variant="contained" color="primary">
          Compose Message
        </Button>
      }
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| icon | ReactNode | null | Icon or illustration to display |
| title | ReactNode | '' | Title text |
| description | ReactNode | '' | Description text |
| action | ReactNode | null | Action button or element |
| variant | 'default' \| 'error' | 'default' | Variant of the empty state |
| sx | object | {} | Custom styles |

## Best Practices

- Use clear, concise language that explains why the state is empty
- Provide a helpful action when appropriate (e.g., "Create New Item")
- Use appropriate icons that match the context
- Keep the design simple and focused
- Use consistent styling with your application's design system
- Consider accessibility (color contrast, alt text for icons, etc.)
