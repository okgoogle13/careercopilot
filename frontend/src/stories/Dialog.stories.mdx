# Dialog

The `Dialog` component is used to display important information or prompt users for input in a modal overlay.

## Basic Usage

```jsx
import { useState } from 'react';
import { Button } from '@mui/material';
import Dialog from '../components/ui/feedback/Dialog';

function Example() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <Button variant="contained" onClick={() => setOpen(true)}>
        Open Dialog
      </Button>
      <Dialog
        open={open}
        onClose={() => setOpen(false)}
        title="Dialog Title"
        contentText="This is the dialog content. You can put any content here."
      />
    </>
  );
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| open | boolean | false | Controls whether the dialog is open |
| onClose | function | - | Callback when the dialog is closed |
| title | string | - | The title of the dialog |
| content | ReactNode | - | The content of the dialog |
| contentText | string | - | The text content of the dialog (alternative to content) |
| actions | ReactNode | - | Custom actions to display in the dialog footer |
| showCloseButton | boolean | true | Whether to show the close button |
| showCancelButton | boolean | true | Whether to show the cancel button |
| cancelButtonText | string | 'Cancel' | The text of the cancel button |
| showConfirmButton | boolean | true | Whether to show the confirm button |
| confirmButtonText | string | 'Confirm' | The text of the confirm button |
| confirmButtonColor | 'primary' \| 'secondary' \| 'error' \| 'info' \| 'success' \| 'warning' | 'primary' | The color of the confirm button |
| isConfirmLoading | boolean | false | Whether the confirm button is in a loading state |
| onConfirm | function | - | Callback when the confirm button is clicked |
| maxWidth | 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| false | 'sm' | The maximum width of the dialog |
| disableBackdropClick | boolean | false | Whether to disable closing the dialog when clicking the backdrop |
| disableEscapeKeyDown | boolean | false | Whether to disable closing the dialog with the escape key |
| divider | boolean | true | Whether to show a divider between the title and content |
| variant | 'default' \| 'fullscreen' \| 'scrollable' | 'default' | The variant of the dialog |
| sx | `SxProps<Theme>` | - | Additional styles for the dialog |
| contentSx | `SxProps<Theme>` | - | Additional styles for the dialog content |
| titleSx | `SxProps<Theme>` | - | Additional styles for the dialog title |
| actionsSx | `SxProps<Theme>` | - | Additional styles for the dialog actions |

## Methods (when using ref)

When using the `Dialog` with a ref, you can control it with the following methods:

```typescript
interface DialogRef {
  open: () => void;     // Opens the dialog
  close: () => void;    // Closes the dialog
  isOpen: boolean;      // Whether the dialog is currently open
}
```

## Best Practices

- Use dialogs to request user input or display important information that requires attention
- Keep dialog content concise and focused
- Provide clear and descriptive button labels
- For destructive actions, use a confirmation dialog with a warning message
- For complex forms, consider using a fullscreen dialog
- Use the `disableBackdropClick` prop to prevent accidental dismissal of important dialogs
