# Usage Guidelines

## CSS Implementation

```css
.asset-night-contemplation {
    background-image: url('/assets/kr-solidarity/heroes/night-contemplation-004');
    background-size: cover;
    background-position: center;
}

/* Opacity by context */
.kr-solidarity-hero { opacity: 1.00; }
.kr-solidarity-content { opacity: 0.85; }
```

## Responsive Behavior

- Desktop: Full resolution, variable font states mapped to scroll.
- Tablet: Scale proportionally.
- Mobile: Crop to 3:4 profile center weighted.

## Component Integration

Recommended for: Main Landing Pages, Hero Modules
Avoid for: Small cards, dense UI utility components
