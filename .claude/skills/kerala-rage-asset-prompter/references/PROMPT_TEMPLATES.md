# Prompt Templates by Asset Category

Use these standardized structures to ensure consistency across different Kerala Rage asset types.

## 1. Hero Illustration (16:9)
**Purpose**: Landing pages, primary dashboard headers.

```text
Professional stencil illustration of [Subject] for a landing page hero. 
Style: Kerala Rage 'Solidarity Mode', Melbourne laneway street art. 
Palette: Background --sys-color-charcoalBackground-base (#0F0F0F), Highlights --sys-color-solidarityRed-base (#F14714) and --sys-color-inkGold-base (#DAF674). 
Composition: Overlapping geometric slabs with asymmetric stone radii, disruptive visual hierarchy.
Aesthetic: Gritty spray-paint textures, heavy stencilled shadows, sharp vector-like edges.
Technical: 16:9 aspect ratio, 4k resolution, optimized for Nano Banana Pro.
```

## 2. Icon Set (1:1)
**Purpose**: Navigation, utility markers, feature chips.

```text
High-contrast silhouette icon of [Subject], centered in a hand-cut frame.
Style: Industrial stencil-cut, minimal detail, high legibility at 24px.
Palette: Foreground --sys-color-worker-ash-base (#DAF6B3), Background #000000 (transparency-simulated).
Aesthetic: Imperfect 'radius-pebble' edges, hand-stamped look, slightly inconsistent ink bleed.
Technical: 1:1 aspect ratio, centered composition, optimized for Nano Banana Pro.
```

## 3. Decorative Texture (Variable)
**Purpose**: Subtle background depth, wheat-paste ripples.

```text
Abstract background texture of [Pattern/Material].
Style: Melbourne urban grit, weathered wheat-paste paper, charcoal-on-stone grain.
Palette: Monochrome gradients of --sys-color-charcoalBackground-steps (#0F0F0F to #323232).
Aesthetic: Subtle torn edges (--sys-shape-tornEdgeClipPath), ink drip, heavy paper tooth.
Technical: Seamless tiling preferred, low contrast for legibility, optimized for Nano Banana Pro.
```

## 4. Industrial Motif Study (1:1)

## 5. Typography Visualization
**Purpose**: Concept posters, typographic headers.

```text
Typographic poster declaring '[Text/Slogan]'.
Style: Proclamation style using --sys-type-fontFamilies-proclamation (Libre Bodoni) and --sys-type-fontFamilies-colorAccent (Nabla).

Technical: Focus on typographic rhythm and 'slam' impact, optimized for Gemini 3.1 Pro spec drafting.
```
