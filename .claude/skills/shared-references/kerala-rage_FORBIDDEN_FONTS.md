# KR Solidarity: Forbidden Fonts (v6.0)

These fonts signal algorithmic defaults or colonial aesthetics. Using them is a design-system failure.

## ❌ Forbidden Fonts

| Font | Reason |
|---|---|
| **Inter** | Overused, signals generic SaaS/AI-generated UI. |
| **Roboto** | Corporate Material Design default. |
| **Arial / Helvetica** | Bland, overused, signals generic defaults. |
| **Open Sans / Lato** | Dated, clichéd aesthetics. |
| **Lora / Crimson** | Legacy KR v1 — superseded by Fraunces + Libre Bodoni. |
| **Birthstone Bounce** | Legacy KR v1 — superseded by Caveat. |
| **System fonts** | `-apple-system`, `system-ui` etc. — all banned for primary use. |

---

## ✅ Authorized KR Solidarity Stack

These are the **only** authorized fonts. All must be loaded as variable font files (`.woff2`).

### Workhorse (Body & UI)
- ✅ **Work Sans Variable** — `wght` 100–900.

### Display & Expressive
- ✅ **Fraunces Variable** — Hero headlines, emotional subheads.
- ✅ **Libre Bodoni** — Proclamation and declarative statements.

### Technical / Mono
- ✅ **JetBrains Mono** — Code, data, technical annotations.

### Accent / Curator
- ✅ **Caveat** — Handwritten curator notes, signatures.
- ✅ **Nabla (COLRv1)** — **Icon-scale only.** MUST use Solidarity palette.

---

## Rules

1. **Variable files only** — Never import static weight variants.
2. **No system fallbacks as primary** — System fonts are only for deep-fallback.
3. **Nabla is restricted** — Icon-scale decorative use only.
4. **Caveat replaces all script fonts** — Hand-annotated feel only.
