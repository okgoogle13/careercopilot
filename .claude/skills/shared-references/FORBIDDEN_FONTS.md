# Forbidden Fonts (Colonial / Soft / Bourgeois)

The following fonts are **STRICTLY PROHIBITED** in the Kerala Rage design system. They represent colonial politeness, corporate sterility, or Victorian nostalgia.

## The Banned List

- **Fraunces**: (Victorian/Northcote - **BANNED**) - Represents the "Colonial Curator".
- **Lora**: (Colonial Serif - **BANNED**) - Represents "Polite Academia".
- **Crimson Text**: (Old Style - **BANNED**) - Too soft.
- **Playfair Display**: (High Contrast Serif - **BANNED**) - Too elegant/bourgeois.
- **Open Sans / Roboto / Arial**: (Corporate Sterile - **BANNED**) - Represents "The System".
- **Comic Sans / Papyrus**: (Obviously).

## Allowed Substitutes

- **Inter Variable**: The Worker's Font. (Solidarity, Direct Action).
- **Recursive**: The Theoery Font. (Intellectual, Adaptive).
- **Syne**: (Allowed for specific "Art/Propaganda" headers ONLY).
