## Layering System

Assets are organized into semantic layers that determine their composition and usage:

- **substrate**: Material base layer (backgrounds, textures)
- **atmospheric**: Environmental overlays (abstract compositions, patterns)
- **cultural**: Identity anchors (symbols, landscapes)
- **resistance**: Editorial heroes (portraits, street scenes)
- **spiritual**: Mythic anchors (devotional imagery)
- **ui-kit**: Interface elements (SVG icons, motifs, patterns)

## Layering Compatibility Rules

### Can Overlay
- **Substrate** ← Atmospheric, Cultural, Resistance, Spiritual, UI-Kit
- **Atmospheric** ← Cultural, Resistance, Spiritual, UI-Kit
- **Cultural** ← Resistance, UI-Kit
- **Resistance** ← UI-Kit
- **Spiritual** ← UI-Kit

### Cannot Overlay (Same Layer)
- Substrate + Substrate
- Atmospheric + Atmospheric
- Cultural + Cultural
- Resistance + Resistance OR Spiritual
- Spiritual + Spiritual OR Resistance

## Usage Notes

1. **Priority Levels**:
   - **CRITICAL**: Core brand assets (devotional, portraits)
   - **HIGH**: Editorial heroes, cultural symbols, textures
   - **MEDIUM**: UI kit elements, general abstract backgrounds

2. **Small UI Safe**:
   - ✅ Abstract, Symbols, UI Kit (scales down well)
   - ❌ Devotional, Heroes, Portraits, Street (requires large display)

3. **Aspect Ratios**: Assets span multiple ratios for flexible composition:
   - Square: 1:1 (most common)
   - Landscape: 16:9, 11:6, 3:2
   - Portrait: 3:4, 2:3, 24:43, 29:36

4. **When Cataloging New Assets**:
   - Check for duplicates or variants of existing assets
   - Suggest variant naming (e.g., `KR-SOLID-037-v2`) if similar subject found
   - Assign appropriate layer based on semantic function
   - Determine layering compatibility
   - Set priority based on brand criticality
