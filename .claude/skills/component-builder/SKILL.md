# Component Builder Skill (v2.0)

**Role:** Production-grade UI Component Creator for Kerala Rage
**Context:** Material 3 Expressive + "Agit-Prop / Viscous Fluidity" Aesthetic
**Output:** Production-ready React/TypeScript components with 100% token compliance

## Core Principles

### 1. The Solidarity Typography Stack

NEVER use Roboto (static), or System fonts. Use only:

- **Agit-Prop** (`Inter Display Black 900`): Hero moments.
- **Solidarity** (Heavy/Bold): The ONLY mode. High-contrast, localized beauty, visceral interaction.
- **Theory**: ABOLISHED.
- **kr-dark**: ABOLISHED.
- **Direct Action** (`Inter Variable`): Functional body/UI.

### 2. Kerala Rage Morphology

- **Torn Edges**: Use `clip-path-tear`, `radius-none`.
- **Elevation**: Use `shadow-viscous`, `shadow-hover-rise`.
- **Texture**: Apply `bg-noise` or `halftone-grid` to surfaces where appropriate.

### 3. Logic & Accessibility

- **ARIA First**: Every interactive element must have `aria-label` or `aria-labelledby`.
- **States**: Handle `loading`, `disabled`, `error`, and `empty` states explicitly.
- **Micro-interactions**: Use `transition-all duration-short ease-viscous` for hovers.

## Workflow

3.  **Receive Spec**: Get component name and props.
4.  **Mode Enforcement**: REJECT any request for "Theory", "Lab", or "kr-dark" mode. FORCE "Solidarity".
5.  **Generate Code**:
    - Use `lucide-react` for icons.
    - Use `framer-motion` for complex physics.
    - Use `clsx` and `tailwind-merge` for class management.
6.  **Verify Compliance**: check against "Anti-Slop" rules.

## Example Usage

Input: "Create a ManifestoCard component for the Solidarity mode that shows a title and action."

Output: A component using `clip-path-tear`, `Inter Display Black` for titles, and `shadow-viscous` for hover.
