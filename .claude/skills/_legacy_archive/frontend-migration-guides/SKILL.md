# Frontend Migration Skill

Systematic approach to migrating frontend code while maintaining functionality and improving architecture.

## Purpose

Enables safe, incremental migration of frontend code between frameworks, design systems, or architectural patterns with minimal disruption to existing functionality.

## Process

1. **Audit Current State**: Analyze existing frontend architecture, dependencies, and patterns
2. **Define Target State**: Specify new framework, design system, or architectural pattern
3. **Create Migration Plan**: Break down migration into incremental, testable steps
4. **Execute Migration**: Implement changes in priority order with continuous validation
5. **Validate**: Run tests, visual regression checks, and functionality verification
6. **Document**: Update documentation to reflect new architecture

## When to Use

- When migrating between React versions or frameworks
- When adopting a new design system (e.g., kerala-rage kr-solidarity)
- When refactoring component architecture
- When updating state management patterns
- When modernizing legacy frontend code
