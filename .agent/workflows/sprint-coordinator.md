# Sprint Coordinator

Use this skill to run sprint planning and monitor release cadence. Turn sprint goals into actionable milestones, task dependencies, readiness scoring, and daily status artifacts.

## Run The Core Workflow

1. Define the sprint frame: capture the objective, start/end dates, named owners, and high-level deliverables.
2. Break the sprint into actionable milestones: define the goal, acceptance criteria, dependencies, and expected completion date for each milestone.
3. Establish task dependencies: explicit mapping of what must complete before subsequent items can start.
4. Establish readiness scoring: calculate sprint health based on completed vs pending tasks and blockers.
5. Daily Status Updates: Track daily progress against sprint goals, bubbling up risks and blockers immediately.

## Enforce These Rules

- Keep this skill focused on sprint delivery and tracking, not technical implementation detail.
- Refuse to advance the sprint state without a concrete progress signal (completed milestone, mitigated risk).
- Prefer measurable delivery signals over subjective progress summaries.
- Escalate blockers that threaten the sprint goals early.
