## Tools & Resources

### Git Commands
```bash
# Full history search for file
git log --all --full-history --follow -- "path/to/file.ts"

# Find when function was deleted
git log --all -p -- "path/to/file.ts" | grep -B10 -A10 "functionName"

# Show file at specific commit
git show <commit-hash>:path/to/file.ts

# Search commit messages
git log --all --grep="functionName"
```

### Frontend Search
```bash
# Recursive grep in frontend
grep -r "functionName" frontend/src/

# Case-insensitive search
grep -ri "functionname" frontend/src/

# Search TypeScript files only
find frontend/src -name "*.ts" -o -name "*.tsx" | xargs grep "functionName"
```

### Code Review
