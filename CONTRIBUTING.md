# Contributing to Kerala Rage

Thank you for your interest in contributing to the Kerala Rage project.

## Design System Canon (Required Reading)

This project is governed by the **Kerala Rage Design System Canon**.

The canon is the authoritative source of truth for:
- Visual identity
- Symbolic and cultural constraints
- Asset usage rules
- AI generation rules
- Banned motifs and representations

📄 Location:
`/docs/design/DESIGN_SYSTEM_CANON.md`

### Contribution Rules

Before submitting a PR that affects:
- visuals
- assets
- content
- AI-generated material
- cultural or symbolic references

you MUST review the Design System Canon.

### Non-Negotiables

- The canon overrides all other documentation.
- Changes that conflict with the canon will not be merged.
- AI-generated assets must comply with canon rules and visual references.
- Canonical visual references in `/docs/design/visuals/` are **style anchors only** and must not be copied or remixed literally.

### Modifying the Canon

Changes to the Design System Canon:
- Require explicit justification in the PR description
- Must update both the markdown and `/visuals` index if relevant
- Should be reviewed by a maintainer familiar with cultural constraints

If you are unsure, choose the **more restrictive interpretation**.
