# User Profile Setup

## Instructions

To enable the **Ghostwriter Agent** to generate tailored cover letters, you need to provide your resume.

### Step 1: Add Your Resume

1. Open the file `user_profile/resume.md`
2. Paste your complete resume in Markdown format
3. Save the file

### Resume Format Guidelines

Your resume should include:

- **Contact Information** (Name, Email, Phone, LinkedIn)
- **Professional Summary** (Brief overview of your expertise)
- **Work Experience** (Role, Company, Dates, Key achievements)
- **Education** (Degrees, Institutions, Years)
- **Skills** (Technical skills, soft skills, certifications)
- **Notable Projects** (Optional but recommended)

### Example Structure

```markdown
# [Your Name]

**Email:** your.email@example.com
**Phone:** +61 XXX XXX XXX
**LinkedIn:** linkedin.com/in/yourprofile

## Professional Summary

[Brief 2-3 sentence summary of your career and expertise]

## Work Experience

### [Job Title] | [Company Name]
*[Start Date] - [End Date]*

- Key achievement or responsibility
- Quantified impact where possible
- Relevant technologies/methodologies used

### [Previous Role] | [Company]
*[Dates]*

- [Achievements]

## Education

**[Degree]** | [University Name]
*Graduated: [Year]*

## Skills

- **Technical:** Python, React, FastAPI, etc.
- **Soft Skills:** Team leadership, strategic planning, etc.
- **Certifications:** [Any relevant certifications]
```

### Privacy Note

Your resume is stored **locally only** in this directory and is never uploaded anywhere without your explicit consent. It is only used by the Ghostwriter Agent running on your machine.
