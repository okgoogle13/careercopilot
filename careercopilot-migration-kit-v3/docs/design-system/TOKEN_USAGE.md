# Token Usage

Use the canonical parent-repo sources only:

- `frontend/src/design/tokens/tokens.json`
- `frontend/src/design/styles/design-tokens.css`

Allowed variable families:

- `--sys-color-*`
- `--sys-shape-*`
- `--sys-type-*`

Do not introduce hardcoded `#hex`, `rgb(a)`, or `hsl(a)` values in migrated screen code.
