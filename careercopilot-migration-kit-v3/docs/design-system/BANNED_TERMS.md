# Banned Terms

- Deprecated tokens: `labWrenMetalBlue`, `GumLeafGreen`, `WattleGold`, `inkGreen`
- Botanical references: `flora`, `botanical`, `botanist`, `wattle`, `gum leaf`, `eucalyptus`
- Deprecated archetypes in new code: `Jar`, `Cabinet`, `Seed`, `Leaf`

Use `Pebble`, `Stone`, and `Slab` naming instead.
