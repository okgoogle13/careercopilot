# Dashboard Copy Guide

Use this guide before a migrated dashboard route is treated as `copy-cleared`.

## Approved Framing

- movement overview
- active roles
- draft queue
- signals
- next move
- review

## Avoid

- worker overview
- migration
- rollback
- placeholder
- legacy route
- feature flag

## Required Checks

- status messaging is user-facing, not implementation-facing
- actions describe what opens next
- supporting copy frames the dashboard as coordinated work, not admin tooling
- rendered text is ready for screenshot review before visual audit
