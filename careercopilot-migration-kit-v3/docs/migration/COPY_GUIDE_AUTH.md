# Auth Copy Guide

Use this guide before a migrated auth route is treated as `copy-cleared`.

## Approved Framing

- collective
- movement
- dashboard
- next step
- access
- account

## Avoid

- worker portal
- workspace
- worker access
- worker account
- migration
- feature flag
- fallback
- rollback
- placeholder

## Required Checks

- CTA states the next step or outcome
- labels and helper copy are direct
- no developer or rollout language appears in rendered JSX
- auth routes use benchmark-aligned tone before screenshot capture
