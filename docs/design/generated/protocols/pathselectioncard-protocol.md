# Protocol: PathSelectionCard (Kerala Rage)

## Design Identity: Solidarity Mode
- **Status**: New Construction
- **Primary Register**: Possibility & Guidance
- **Core Narrative**: Choosing a path within the collective coalition, selecting a role that honors both individual skill and community need.

## Visual Hierarchy
- **Dominant**: `radius-stone` card with a `radius-pebble` action button.
- **Primary Ink**: Signal Green (#48F0E5) for hybrid identity and discovery.
- **Secondary Ink**: Ink Gold (#DAF674) for optimistic path selection.
- **Substrate**: Charcoal Background with Blueprint Grid (8% opacity).

## Motion Physics
- **Entrance**: Stencil Slam with a "Slide" momentum from the left.
- **Interaction**: Hover "Bloom" (+100 weight) and shadow expansion.

## Anti-Slop Protocol
- **Banned**: border-radius 8px.
- **Required**: `radius-stone` for the cards.
- **Required**: `Inter Variable` for path titles (72px Display Large).
