# Protocol: ProfileHeader (Kerala Rage)

## Design Identity: Solidarity Mode
- **Status**: Migration (Refactoring from UserProfile)
- **Primary Register**: Identity Assertion & Dignity
- **Core Narrative**: Documenting the self as a site of collective power, migrant pride, and resilient history.

## Visual Hierarchy
- **Dominant**: User Portrait or Avatar with screenprint texture overlay.
- **Primary Ink**: Ink Gold (#DAF674) for the name and high-impact identity markers.
- **Secondary Ink**: Signal Green (#48F0E5) for hybrid identity bio/tags.
- **Substrate**: Charcoal Background (#1A1A1A).

## Motion Physics
- **Entrance**: Spring Elastic (800ms) with identity "Bloom".
- **Interaction**: Profile tags "flicker" on hover into higher typographic weight.

## Anti-Slop Protocol
- **Banned**: border-radius 8px, Passport/Visa counter imagery.
- **Required**: `radius-stone` for the profile container.
- **Required**: `Inter Variable` with high weight contrast (100 -> 900).
