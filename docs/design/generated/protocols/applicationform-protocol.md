# Protocol: ApplicationForm (Kerala Rage)

## Design Identity: Solidarity Mode
- **Status**: New Construction
- **Primary Register**: Gravity & Integrity
- **Core Narrative**: Depositing history, documenting resilience, technical precision meeting human story.

## Visual Hierarchy
- **Dominant**: Large "Deposit" drop-zone with dashed blueprint borders.
- **Primary Ink**: Baru Gold (#DAF674) for success confirmations and primary labels.
- **Secondary Ink**: Waratah Red (#F14714) for drag-over highlights and errors.
- **Substrate**: Charcoal Paper (Z-0) with Blueprint Watermark (Z-1).

## Motion Physics
- **Entrance**: Scale Spring (800ms) for the drop-zone.
- **Success**: Verification Stamp "Hits" (Scale 2.0 -> 1.0, Rotate -30deg -> -5deg).

## Anti-Slop Protocol
- **Banned**: border-radius 8px, Passport/Visa imagery, Generic "File Upload" icons.
- **Required**: `radius-slab` (4px) for the main deposition container.
- **Required**: `JetBrains Mono` for drop-zone instructions.
