# Protocol: ManifestoCard (Kerala Rage)

## Design Identity: Solidarity Mode
- **Status**: Migration (Refining existing structure to M3 Expressive)
- **Primary Register**: Defiance & Identity Assertion
- **Core Narrative**: Street grit, archival memory, cultural power.

## Visual Hierarchy
- **Dominant**: Kerala Elephant (80% weight, abstract/stencil)
- **Primary Ink**: Waratah Red (#F14714) for titles and accents.
- **Secondary Ink**: Baru Gold (#DAF674) for primary actions.
- **Substrate**: Charcoal Background (#1A1A1A).

## Motion Physics
- **Entrance**: Spring Elastic (600ms) - "Stencil Slam"
- **Interaction**: Bloom (+100 weight) on hover, Pressed (scale 0.98) on active.

## Anti-Slop Protocol
- **Banned**: border-radius 8px.
- **Required**: `radius-stone` (16px 4px 12px 24px) for the card body.
- **Required**: `radius-pebble` (20px 6px 16px 28px) for the action button.
