# Protocol: LoginCard (Kerala Rage)

## Design Identity: Solidarity Mode
- **Status**: New Construction
- **Primary Register**: Trust & Access
- **Core Narrative**: Verification, entry into the collective archive, security.

## Visual Hierarchy
- **Dominant**: Halo Disk (60% opacity, Ink Gold radiance behind the card)
- **Primary Ink**: Paper White (#F5F0E8) for labels and primary text.
- **Secondary Ink**: Ink Gold (#DAF674) for the "Enter Archive" action.
- **Substrate**: Charcoal Background (#1A1A1A).

## Motion Physics
- **Entrance**: Spring Elastic (600ms)
- **Error**: Shake (200ms) on invalid login.
- **Success**: Lift + Glow (600ms) on verification.

## Anti-Slop Protocol
- **Banned**: border-radius 8px, Passport/ID imagery.
- **Required**: `radius-stone` (16px 4px 12px 24px) for the card.
- **Required**: `radius-slab` (4px) for input fields.
