# Visual References (Canonical)

This folder contains authoritative visual references for the
Kerala Rage Design System.

These images are:
- Style anchors only
- Used to align texture, contrast, grain, and symbolic restraint

They are NOT:
- Layout templates
- Assets to be copied literally
- Sources to merge symbols from

If a generated or designed asset conflicts visually with these references,
the asset must be rejected or regenerated.

Do NOT embed images in markdown.
