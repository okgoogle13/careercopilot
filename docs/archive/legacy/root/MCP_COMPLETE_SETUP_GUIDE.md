## 🐛 Troubleshooting

### Servers still don't appear?
```bash
# Check latest logs for errors
cat ~/.config/Antigravity/logs/$(ls -t ~/.config/Antigravity/logs/ | head -1)/main.log | grep -i mcp

# Check if config file is being read
grep -r "mcp_config.json" ~/.config/Antigravity/logs/$(ls -t ~/.config/Antigravity/logs/ | head -1)/
```

### Package installation errors?
```bash
# Clear npm cache
npm cache clean --force

# Reinstall
python3 tools/bootstrap_mcp.py
```

### IDE not detecting workspace config?
```bash
# Verify .vscode/mcp.json exists
cat .vscode/mcp.json

# Try reloading window
# In Antigravity: Ctrl+Shift+P → "Developer: Reload Window"
```
