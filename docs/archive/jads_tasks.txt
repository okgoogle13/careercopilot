## Jules Execution Instructions

1. **Process in Order**: Execute batches sequentially 1 → 8 to build test patterns progressively
2. **Parallel Option**: Can execute Batch 4 (easiest) in parallel with others for quick wins
3. **Handover Hook Compliance**: Every batch must create the report file specified in the task line
4. **Path Format**: All file paths in reports must be relative (./frontend/src/...) not absolute
5. **Commit Pattern**: Create one commit per batch with message "test: Add [Batch N] tests for [component list]"
6. **Report Location**: Save all reports to ./.ai_reports/ directory
7. **Success Criteria**: Each batch should achieve documented pass rate before proceeding to next

## Success Metrics for All Batches

- ✅ All component tests in __tests__/ directories
- ✅ Comprehensive test coverage (15-25 tests per component)
- ✅ Pass rate at or above batch target
- ✅ Handover report created with accurate metrics
- ✅ Relative paths used throughout
- ✅ Single-line flat task format respected
