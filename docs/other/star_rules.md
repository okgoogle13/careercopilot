# STAR Method Rules & Transformation Guide

## Core Instruction for AI Generation
When generating, formatting, or revising achievements and Key Selection Criteria (KSC) responses, you must strictly adhere to the STAR framework.

## Definitions
* **Situation:** The specific context, background, or challenge.
* **Task:** The specific problem, goal, or responsibility that needed to be addressed.
* **Action:** The explicit, proactive steps taken to address the task. Use strong action verbs.
* **Result:** The quantifiable outcome or impact of those actions.

## Core Rule: Quantification
Always quantify the results whenever possible using numbers, percentages, timeframes, caseload sizes, or specific metrics. Never leave a result vague if a metric can be inferred or requested.

## Transformation Example
* **Weak Simple Description (Do not use):** "Helped improve website performance."
* **STAR Transformation (Required format):** "Identified slow page load times affecting user retention (Situation/Task). Implemented lazy loading for images and minified CSS/JS assets (Action). Reduced average page load time by 40%, resulting in a 15% increase in daily active user retention (Result)."
