# 🚀 CareerCopilot v1.0 - Quick Reference Card

## One-Line Start
```bash
python3 run_copilot.py
```

## What Opens
- 🖥️  Backend: http://localhost:8000
- 🎨 Frontend: http://localhost:5173/job-queue
- 📚 API Docs: http://localhost:8000/docs

## Workflow (5 Seconds)
1. **Clip** → Save job URL
2. **Analyze** → Click "Analyze with JobScout"  
3. **Draft** → Click "Draft Application"
4. **Apply** → Copy and customize

## Stop Application
```bash
Ctrl+C
```

## Files You Need
- ✅ `user_profile/resume.md` - Your resume (REQUIRED)
- ⚠️ `credentials.json` - Google integration (optional)
- ⚠️ `firebase_credentials.json` - Data persistence (optional)
