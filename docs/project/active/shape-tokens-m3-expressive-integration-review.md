## 4. Conflict Risk Check Checklist (Run Before Merging)

Once the PR is visible, verify the following before merging into `feat/prototype-harvest-ready-prep`:

- [ ] **Additive only:** PR adds new entries to `tokens.json` without modifying existing `$value` fields of canonical tokens

- [ ] **CSS regenerated consistently:** Confirm `design-tokens.css` in the PR was regenerated from `tokens.json` using `python3 scripts/build-m3-tokens.py` (not hand-edited)

- [ ] **No circular aliases:** New tokens reference concrete values, not `{sys.shape.*}` alias paths
- [ ] **TypeScript compiles:** Run `cd frontend && yarn type-check` post-merge — catches `SHAPE_TOKENS` omissions instantly
